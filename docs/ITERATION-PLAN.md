# TBox 优化顺序与迭代计划

> 基线：v2.3.0（已发布） · 制定日期：2026-11-06  
> 依据：[项目健康度分析与优化建议](ANALYSIS-PROJECT-HEALTH.md)  
> 原则：先保护数据与稳定性，再做高频效率入口；不推倒重写，不提前引入插件/云同步。

## 1. 优先级总览

| 顺序 | 主题 | 内容 | 版本 | 状态 |
| --- | --- | --- | --- | --- |
| P0 | 可靠性 | 保存失败重试、可等待启动、ShellHost 错误日志与托盘恢复、开机启动失败可见 | 并入 v2.4.0 | 已完成（工作区） |
| P1 | 效率入口 | **胶囊自定义**、**全局搜索**（Ctrl+Shift+T）、托盘入口 | v2.4.0 | 已完成（工作区） |
| P2 | 数据资产 | 导出/导入（全部/单盒）、自动备份保留、升级前备份、版本校验 | v2.5.0 | 待排期 |
| P3 | 多盒子体验 | 同边胶囊避让、窗口懒创建/回收、跨盒拖拽、多显示器位置恢复 | v2.6.0 | 待排期 |
| P4 | 系统集成 | 资源管理器「添加到 TBox」、通知、开机启动状态修复 | v2.6.x | 待排期 |
| P5 | 交付与测试 | CI 功能测试矩阵、安装版、升级迁移、自动更新 | v2.7.0 | 待排期 |

## 2. 今天（v2.4.0，已完成，待提交）

### 胶囊自定义

- 每个分组独立记录最多 3 个胶囊工具；
- 右键工具卡片 →「胶囊」→「固定到胶囊 / 取消固定」；
- 胶囊按分组内卡片顺序显示已固定的工具；拖拽卡片即可调整顺序；
- 没有固定项时保持原来的“前 3 个工具”回退行为；
- 卡片显示小 📌 角标；
- 数据兼容 v2，旧配置不需要迁移。

### 全局搜索

- 新快捷键 `Ctrl+Shift+T` 呼出全局搜索面板（也可从托盘菜单打开）；
- 搜索所有盒子和分组，匹配名称/描述/关键字；
- 结果展示所属盒子/分组；↑↓ 选择、Enter 启动、Esc 关闭；
- 结果按名称匹配优先级排序，最多显示 50 条；
- 不修改当前盒子的面板搜索行为。

### 可靠性（并入本版）

- DataStore 保存失败保留 dirty 并 2 秒重试；
- `BoxManager.StartAsync` 可等待，启动失败不再误报 Activated；
- ShellHost 检查 Win32 返回值、监听 TaskbarCreated 恢复托盘；
- 开机启动注册失败在设置页提示。

## 3. 后续迭代

### v2.5.0 数据资产与收藏

- 收藏工具、最近使用（与胶囊固定互不覆盖）；
- 全局搜索优先展示收藏/最近使用；
- 导出全部/单个盒子，导入时校验版本并先备份；
- 自动保留最近 7 天配置备份。

### v2.6.0 多盒子与系统集成

- 同一屏幕边缘多个胶囊自动堆叠/避让；
- 非活跃盒子面板按需创建、长期不用销毁；
- 跨盒子拖拽工具（最后做）；
- 多显示器位置与 DPI 恢复；
- 资源管理器右键「添加到 TBox」；
- 开机启动状态检测与一键修复、系统通知。

### v2.7.0 稳定性与交付

- 为 DataStore / Launcher / Search / Docking / 多盒子增加冒烟测试；
- CI 覆盖 100%/125%/150%/200% DPI 和 Lite/Full 启动；
- 安装版与绿色版共存规则、升级前备份、卸载保留数据；
- 更新日志与自动检查更新（在数据迁移稳定之后）。

## 4. 暂不做

- 插件/第三方扩展生态：等核心数据模型和命令入口稳定后再评估；
- 云同步、账号、遥测：继续保持本地优先；
- 复杂文件管理：不偏离“工具启动入口”的定位。

## 5. 每版验收底线

- 断网可用，配置保存失败可重试；
- 旧版本数据升级前有备份，升级失败可恢复；
- 多盒子、贴边、胶囊在 100% 和 200% DPI 下不遮挡、不抢焦点；
- Lite / Full 包都能完成启动、添加、启动工具、隐藏/唤回；
- 新增快捷键可配置或有托盘入口兜底。
